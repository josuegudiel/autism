# 🧩 Autism — Respaldo en la nube

> ## ⚠️ Este repositorio es PÚBLICO
>
> Cualquiera en internet puede leer lo que subas aquí, y **lo subido queda en el
> historial de git para siempre**: borrarlo después no lo hace desaparecer.
>
> **No arrastres la carpeta completa.** Sube solo los archivos del proyecto, uno
> a uno o por subcarpetas, y **deja fuera**:
> - el informe médico del niño (`Report-*.pdf`) y cualquier otro PDF clínico,
> - `PROYECTO.md` y cualquier nota con datos personales o rutas de tu ordenador,
> - claves de API, `.env`, `.claude/`.
>
> El archivo `.gitignore` de este repositorio protege esa lista **solo cuando
> subes desde la terminal con `git`**. La subida por el navegador que se explica
> más abajo **se salta el `.gitignore` por completo**: ahí el filtro eres tú.

Este repositorio guarda en la nube todo el contenido de la carpeta
**AUTISMO AGENT** que está en el escritorio de la PC. Así queda respaldado y
accesible desde cualquier lugar.

## 📁 Estructura

```
autism/
└── agente-autismo/     ← aquí van tus archivos
```

## ⬆️ Cómo subir tus archivos (desde la PC, en el navegador)

1. Abre este enlace directo para subir archivos:
   **https://github.com/josuegudiel/autism/upload/main/agente-autismo**
2. Arrastra **solo los archivos del proyecto** al recuadro, después de revisar la
   lista de exclusiones del aviso de arriba.
3. Baja y haz clic en el botón verde **"Commit changes"**.

> 💡 Si tienes subcarpetas, puedes arrastrarlas y GitHub conserva la estructura,
> pero revisa antes qué hay dentro: por esta vía no actúa el `.gitignore`. Los
> archivos no pueden pesar más de 25 MB.
